# طرح: نمایش عریض محتوای وب پیست‌شده

## هدف
وقتی کاربر محتوای HTML قالب‌دار را از وب‌سایتی در DataSave پیست می‌کند، پیش‌نمایش بر اساس همان محتوای کپی‌شده نمایش داده شود و محدودیت عرض قاب سند معمولی اعمال نشود.

## رفتار پیشنهادی
- تشخیص حالت وب فقط هنگام پیست محتوای HTML غنی (clipboard دارای `text/html`) انجام شود.
- محتوای HTML پاک‌سازی‌شده از نظر امنیتی در پیش‌نمایش درج شود؛ عناصر اجرایی و استایل‌های ناامن اجرا نشوند.
- در این حالت قاب پیش‌نمایش از `max-width` سند عادی خارج شود تا از فضای موجود استفاده کند.
- متن ساده و فایل‌های Markdown در حالت سند فعلی باقی بمانند.
- استایل‌هایی که فقط از فایل CSS خارجی سایت می‌آیند قابل بازیابی نیستند؛ ظاهر قابل حفظ محدود به HTML و استایل‌های همراه کلیپ‌بورد است.

## معیار پذیرش
1. پیست HTML غنی، حالت عریض را فعال کند و چیدمان‌های امن همراه کلیپ‌بورد تا حد امکان حفظ شوند.
2. پیست متن ساده یا بازکردن Markdown باعث فعال‌شدن حالت عریض نشود.
3. اسکریپت و محتوای اجرایی از HTML پیست‌شده اجرا نشود.
4. کاربر بتواند با پاک‌کردن محتوا/شروع سند تازه به حالت عادی برگردد.
