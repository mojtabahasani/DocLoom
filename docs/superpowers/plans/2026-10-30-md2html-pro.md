# MD2Html Pro — برنامهٔ اجرا

مرجع طراحی: `docs/superpowers/specs/2026-10-30-md2html-pro-design.md` (در این برنامه «اسپک» نامیده می‌شود).
مرجع رفتار قدیمی: `1file-old/MD2Html.html` (فقط‌خواندنی؛ هرگز ویرایش نشود).

## روش کار
- هر بسته را یک زیرعامل Sonnet اجرا می‌کند. بسته‌ها به ترتیب اجرا می‌شوند، چون همه به `app.js` و `store` دست می‌زنند.
- پایان هر بسته: `npm test` سبز، `npm run build` موفق و زیر سقف حجم، دود مرورگر با Playwright MCP (سرور محلی `python3 -m http.server`؛ مسیر `file:` در MCP بسته است)، و یک commit با پیام انگلیسی.
- زیرعامل اسپک را خلاصه نمی‌کند و تغییر نمی‌دهد. اگر جایی از اسپک ناشدنی بود، در گزارشش می‌نویسد و ساده‌ترین جایگزین امن را می‌سازد.
- گزارش زیرعامل کوتاه باشد: چه ساخته شد، چه تست شد، چه ناتمام ماند، حجم build.
